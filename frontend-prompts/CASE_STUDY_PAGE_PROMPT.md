# Case Study Page Prompt for Frontend Agent

Create a case study page for **Allocate** that reads like a premium product story and showcases the platform as a real-world SaaS solution.

## Case Study Goal
Explain the problem, the solution, and the impact of the platform in a way that supports trust, conversion, and product understanding.

## Design Requirements
- Use **Tailwind CSS** and **shadcn/ui**
- Make it feel editorial, polished, and modern
- Use a strong hero, metrics sections, narrative blocks, and quote-style callouts
- Keep the layout visually balanced with whitespace and emphasis on key outcomes
- The page should work well on mobile and desktop

## Recommended Case Study Structure
1. Hero section with project summary
2. Problem statement
3. Solution overview
4. Key features delivered
5. UX / product flow explanation
6. Metrics or outcome section
7. Screens or component highlights
8. Lessons learned or implementation notes
9. CTA section

## Story Angle
Position Allocate as a platform for managing organization resources, bookings, team access, credits, and notifications.

## Topics To Cover
- How the platform handles multi-tenant organization workflows
- How resource availability and booking rules reduce manual coordination
- How credit-based billing makes usage tracking simple
- How real-time notifications improve responsiveness
- How admin and staff dashboards give different users the right level of visibility

## Example Case Study Framing
- Challenge: Teams needed a single system to manage bookings, usage, billing, and notifications
- Solution: Build an organization-scoped platform with resources, rules, bookings, payments, and inbox features
- Result: Faster scheduling, clearer oversight, and better operational visibility

## UI/UX Notes
- Use callout cards for outcomes and insights
- Add a timeline or flow diagram for the user journey
- Include highlighted stats in large type
- Use shadcn `Card`, `Separator`, `Badge`, `Tabs`, `Table`, and `Accordion`
- Add a polished quote or testimonial block if available

## Recommended Copy Tone
- Confident and product-focused
- Clear but not overly technical
- Outcome-driven and business-friendly
- Short, scannable paragraphs with strong headings
