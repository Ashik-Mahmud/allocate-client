# Landing Page Prompt for Frontend Agent

Build a modern SaaS landing page for **Allocate**, a multi-tenant workspace and resource booking platform.

## Product Goal
The page should explain how Allocate helps organizations manage rooms, desks, bookings, credits, subscriptions, notifications, and team operations in one system.

## Design Requirements
- Use **Tailwind CSS** and **shadcn/ui** components
- Style should feel premium, modern, and enterprise-ready
- Use a strong visual hierarchy with bold headline, concise subheadline, and clear CTA buttons
- Include subtle gradients, soft borders, layered cards, and polished spacing
- Avoid generic default layouts; make it feel intentional and high-end
- Ensure the page is responsive and mobile-friendly and dark mode support
- Use charts, badges, icons, and small product preview sections where appropriate (lucid icon)

## Landing Page Sections
1. Hero section with headline, subheadline, primary CTA, and secondary CTA
2. Trust or metrics row with numbers like organizations, bookings, credits, and uptime
3. Core feature highlights
4. Product workflow section showing how the platform works
5. Real-time notifications and inbox section
6. Payments, credits, and subscription section
7. Dashboard preview section for org admin and staff
8. FAQ section
9. Final CTA section

## Feature Angles To Highlight
- Multi-tenant organization management
- Resource booking with flexible scheduling rules
- Credits and subscription-based billing
- Real-time notifications and reminders
- Role-based access for admins, org admins, and staff
- Availability checking, maintenance mode, and booking control

## Copy Direction
- Headline should be concise and outcome-driven
- Use benefit-first messaging instead of technical jargon
- Mention efficiency, control, visibility, and automation
- Keep the body copy short and scannable

## Suggested Hero Copy
- Headline: Smart resource booking for modern teams
- Subheadline: Manage organizations, resources, bookings, credits, and notifications in one enterprise-ready platform.
- Primary CTA: Explore Features
- Secondary CTA: View Case Study

## Section Copy Ideas
- Resources: Manage rooms, desks, and bookable assets with custom rules and availability controls.
- Bookings: Create, confirm, reschedule, or cancel bookings with clear status tracking.
- Credits: Track usage, top up balance, and monitor transactions across your organization.
- Notifications: Send reminders, mark items read, and keep teams updated in real time.

## UI Notes
- Use a large hero card with dashboard preview imagery
- Include a compact metrics strip
- Add a feature grid with 3 or 4 cards
- Use shadcn `Button`, `Card`, `Badge`, `Tabs`, and `Accordion`
- If charts are shown, keep them lightweight and visually elegant
