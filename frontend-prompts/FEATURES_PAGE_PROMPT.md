# Features Page Prompt for Frontend Agent

Create a dedicated features page for **Allocate** using a modern SaaS style.

## Page Objective
Show the full product capability set in a structured, persuasive way so visitors can understand what the platform does and why it is valuable.

## Design Requirements
- Use **Tailwind CSS** and **shadcn/ui**
- Prefer a clean enterprise layout with card grids, sections, and icon-led feature blocks
- Use clear section headings and short feature descriptions
- Make the page feel polished, scalable, and easy to scan
- Include visual grouping by product area
- Optimize for desktop and mobile

## Recommended Structure
1. Header section with page title and summary
2. Feature category grid
3. Detailed feature sections
4. Role-based usage section
5. Integrations and technical foundation section
6. Security and control section
7. Final CTA block

## Feature Categories To Include
- Authentication and access control
- Organization management
- Resource management
- Resource rules and availability engine
- Booking lifecycle management
- Payments, credits, and subscriptions
- Notifications and inbox
- Dashboard and analytics
- Community and collaboration
- Admin and platform control

## Content Guidance
- For each feature, explain the user value first
- Keep technical details concise, but mention the implementation where helpful
- Use icons, tags, and short supporting copy
- If you add screenshots or mockups, organize them by module

## Suggested Page Messaging
- Title: Everything you need to manage resources and bookings
- Subtitle: Allocate gives admins and staff one place to manage scheduling, credits, notifications, and organizational workflows.

## UI/UX Notes
- Use a sticky sub-navigation or section index if the page is long
- Use `Badge` for statuses and capability tags
- Use `Tabs` or segmented controls to switch between admin, org admin, and staff views
- Include a comparison-style section if needed to show which role gets which tools
- Add a final CTA with a strong visual treatment
